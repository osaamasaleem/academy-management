# Academy Management System (AMS)

Internal web platform for Grade 1–12 coaching academy management (Admin & Teacher roles).

## Structure
- `/backend`: Node.js (Express), PostgreSQL, JWT Auth in HttpOnly cookies.
- `/frontend`: React (Vite), Tailwind CSS, TanStack Query, React Router.
- `/docs`: Full technical specifications and architecture.

## Setup & Running Locally
See instructions in `backend/` and `frontend/` directories.
- `npm run dev:backend` - Starts Express API on port 5000.
- `npm run dev:frontend` - Starts Vite dev server with proxy to backend.
